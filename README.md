# デュエキング2026 4コンチェッカー

DM26-EX4「切札不滅!! デュエキング FOREVER 2026」用のスマホ向けPWA所持数チェッカーです。

## 管理対象

- 通常版 99種：4コン（396枚）管理
- デュエキングMAX 50種：1枚以上で所持済み
- シークレット 25種：1枚以上で所持済み
- ゴールドデュエキングMAX 12種：1枚以上で所持済み

## 操作

- カード画像タップ：拡大
- 枚数ボタンタップ：現在の入力モードを +1
- `−`：現在の入力モードを -1
- 入力モード：所持数 / 注文予定 / デッキ使用
- 注文予定があるカードを所持数モードで増やすと、注文予定から所持へ1枚振り替え
- 4コン進捗は「所持数 − デッキ使用数」で算出した専用ストレージ枚数を使用
- 5枚目以降の余剰所持は数字には残るが、4コンバーには表示しない

## 色

- 緑：4コン確保済み
- 赤：所持しているが4枚未満
- 橙：デッキ使用によりストレージ4枚を侵食している分
- 青：注文予定
